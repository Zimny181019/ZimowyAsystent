Privacy Policy

🤖 Bot: Zimowy Asystent ❄
📅 Effective Date: September 13, 2026
This Privacy Policy explains what data Zimowy Asystent ❄ processes on Discord servers, why it is processed, and how long it is retained. Zimowy Asystent combines recruitment/moderation features together with member statistics, verification, and welcome/goodbye messaging in a single bot.

📋 Data We Collect

  • 👤 User IDs (of applicants, moderators, staff, and members who interact with the bot)
  • 🏠 Server (Guild) ID
  • 💬 Channel IDs used for recruitment, announcements, moderation, statistics counters, and verification features
  • 🎭 Role IDs (used for permission checks and role assignment upon recruitment approval or verification)
  • 📝 Recruitment application answers submitted through forms (e.g. nickname, first name, age, availability, experience, portfolio links, contact information — the exact fields depend on the position applied for)
  • ✍️ Rejection reason text entered by staff when declining an application
  • ⏱️ Timestamps related to recruitment cooldowns and channel access restrictions
  • 📌 Application status (pending / resolved) for each user and role
  • 🟢 Presence status (online / offline) — used only to count how many staff/admins are currently online
  • 📨 Invite codes and invite usage counts, and a record of who invited whom, used for the invite-tracking and member statistics features
The bot does not use the Message Content Intent and does not read, scan, or store the content of ordinary server messages. Presence status is used only in aggregate to power live "admins online" counters and is not stored long-term or shared with third parties.

🗄️ Data Storage

Data is stored locally in a database on the bot's hosting server and used exclusively to support the features described in this Policy. Recruitment cooldown records are automatically deleted once the cooldown period expires. Application answers may be retained for record-keeping of past recruitment decisions unless deletion is requested. Invite-tracking and statistics data are kept only for as long as needed to provide those features, and related records are removed when a user leaves the server.

🤝 Data Sharing

  • ✗ Data is never sold or shared with third parties
  • ✗ Data is never used for advertising purposes outside the server
  • ✓ Recruitment application answers are visible to server staff and recruiters, as this is the core purpose of the recruitment system (reviewing and deciding on applications)

👶 Children

The bot is intended to be used in accordance with Discord's Terms of Service, which require users to be at least 13 years old (or the minimum age required in their country). We do not knowingly collect data from users below this age. Applicants should not provide personal information beyond what is explicitly requested in the recruitment form.

✋ Your Rights

You may request deletion of your data (application answers, cooldown records, pending application status, invite-tracking records) at any time by contacting server staff through the ticket system. You may also withdraw a pending application or choose not to use the bot's recruitment features at any time.

✏️ Changes to This Policy

We may update this Privacy Policy from time to time. Significant changes will be announced on the server. Continued use of the bot after changes take effect constitutes acceptance of those changes.

✉️ Contact

For any questions regarding privacy or data handling, please contact server staff through the ticket system.
